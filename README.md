# end — перенос работы в новый чат Claude Code без потерь

Длинная сессия с агентом тратит лимит: на каждом ходе модель заново читает весь накопленный чат. `/compact` от этого почти не спасает: чтобы написать сводку, модель читает весь чат, после сжатия кэш собирается заново, а чат снова растёт. Дешевле переходить в новый чат на границе этапа, пока контекст небольшой. Но новый чат не помнит старый.

Навык `end` решает это: перед переходом он записывает состояние работы в файлы проекта и выдаёт готовый промпт для нового чата. В комплекте — статусная строка и два хука, которые напоминают, когда пора переходить.

## Что делает навык

По команде `/end` навык записывает в папку `docs/` проекта:

- где вы остановились и что уже сделано (`SESSION_STATE.md`);
- какие решения приняли и почему (`DECISIONS.md`);
- что осталось сделать (`TODO.md`);
- что пробовали и что не сработало, чтобы не повторять;
- один конкретный следующий шаг.

Потом спрашивает, сохранить ли изменения в Git, и выдаёт промпт для нового чата. Вы набираете `/clear` и вставляете промпт. Новый агент сверяет записанное с тем, что на самом деле лежит в проекте, и продолжает работу.

Без вашего ответа навык ничего не сохраняет в Git, не отправляет изменения на GitHub и не останавливает запущенные процессы.

Файлы состояния те же, что у [версии навыка для Codex](https://github.com/paron7433-glitch/end-skill): проект можно начать в одном агенте и продолжить в другом.

## Необязательно: статусная строка и напоминания

- `context_statusline.py` — строка внизу окна Claude Code: `Opus 5 · контекст: занято 28% · 5ч: 23% · 7д: 41%`.
- `context_watch.py` — хук: напоминает, когда контекст занят больше чем на 60, 80 и 90%.
- `turn_watch.py` — хук: напоминает на 100, 200 и 400 ходах модели.

Нужен Python 3.8 или новее.

## Установка

Навык — четыре шага, статусная строка и хуки — отдельно; подробно в [INSTALL.md](INSTALL.md). Как пользоваться каждый день — в [DAILY-USAGE.md](DAILY-USAGE.md).

Можно попросить Claude Code поставить навык самому. Но что бы вы ни ставили извне, сначала прочитайте файлы своими глазами: навыки и хуки — это инструкции и код, которые агент выполнит.

## Где не сработает

- Чат на claude.ai и приложение Claude вне режима Code: навыку нужен доступ к файлам проекта и Git.
- Проект без Git: навык не проверит изменённые файлы и отметит это состояние как неизвестное. Git в проекте есть, если в корне лежит скрытая папка `.git`.
- Хуки и статусная строка требуют Python.

## Состав

| Путь | Что это |
|---|---|
| `.claude/skills/end/` | Сам навык: инструкция, шаблоны файлов состояния, политика «когда /compact, когда /end» |
| `.claude/hooks/` | Статусная строка и два хука |
| `.claude/settings.example.json` | Пример подключения хуков |
| `CLAUDE.fragment.md` | Фрагмент для `CLAUDE.md` проекта |
| `INSTALL.md` | Установка |
| `DAILY-USAGE.md` | Памятка на каждый день |
| `CLAUDE-CODE-CAPABILITIES.md` | Что в комплекте — функция Claude Code, а что — обходной путь |
